# Stress and Memory Simulation

## Project Overview
This project explores how stress may affect memory recall in college students. I created a computational model using RStudio to simulate the differences between a control group and a stress group.

## Purpose
The purpose of this project is to better understand how stress may influence a person's ability to remember information.

## Research Background
This project was guided by research about stress and memory.

Research Article:
https://pmc.ncbi.nlm.nih.gov/articles/PMC6380371/

## Simulation Details
The simulation includes 300 simulated college students:
- 150 students in the control group.
- 150 students in the stress group.

## Variables
- Independent Variable: Stress condition.
- Dependent Variable: Memory recall, measured by the number of items remembered out of 20.

## Software
- R
- RStudio

## Limitations
The data used in this project are simulated and do not represent actual college students. The model is based on patterns discussed in previous research. Stress-and-Memory-Simulation
